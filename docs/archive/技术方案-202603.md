# 房屋状态识别AI项目详细技术方案（更新版）

## 🎯 项目定位
专注租赁场景的智能房屋状态识别SaaS，为租客/房东提供全自动验房、状态评估、报告生成服务，解决传统验房效率低、不透明、纠纷多的痛点。新增AI Agent能力，实现全流程自动化处理、智能交互、主动决策。

---

## 🏗️ 整体架构（云原生+Agent架构）

```
┌─────────────────┐

├─────────────────┤
│ API网关层       │
│ （鉴权/限流/监控/负载均衡）
├─────────────────┤
│ Agent调度层     │  ✨ 新增
│ （任务调度/工具调用/决策引擎/记忆管理）
├─────────────────┤

├─────────────────┤
```

## 🛠️ 技术栈选型（按需求更新）

### 前端（全平台覆盖）
1. **Web端/管理后台**：
   - 框架：Next.js 15+（App Router模式）+ React 19
   - UI组件库：shadcn/ui + Tailwind CSS v3
   - 状态管理：Zustand + React Query
   - 核心能力：图片/视频断点续传、实时进度推送、报告在线预览、AI Agent对话界面
   - 优势：SSR/SSG混合渲染，首屏加载快，SEO友好，支持全栈开发

2. **移动端**：
   - 跨平台框架：React Native 0.75+ + Expo
   - 状态管理：Zustand
   - 原生能力：相机调用、图片压缩、离线缓存、推送通知
   - 发布渠道：iOS App Store + 安卓应用市场 + 企业签名
   - 优势：一套代码多端运行，开发效率高，性能接近原生应用

3. **小程序端**：
   - 框架：Taro + React
   - 兼容微信/支付宝/抖音小程序
   - 核心能力：快速分享、免安装、微信支付对接

### 后端（Python技术栈）
- **语言/框架**：Python 3.12 + FastAPI + Pydantic
  - 优势：生态完善，AI相关库支持好，开发效率高，自动生成API文档
- **微服务拆分**：
  - 用户服务：账号管理、身份认证（OAuth2 + JWT）
  - 订单服务：支付、订单生命周期管理
  - 报告服务：报告生成、导出、分享
  - Agent调度服务：Agent任务管理、工具调用、决策流程
  - 任务调度服务：Celery + Redis，AI任务排队、重试、定时触发
- **数据库**：
  - 关系型：PostgreSQL 16，存储用户/订单/报告结构化数据
  - 非关系型：MongoDB，存储AI识别中间结果、Agent对话历史
  - 缓存：Redis 7，会话缓存、热点数据缓存、消息队列
  - 向量库：Milvus 2.4（本地部署），存储房屋特征向量、Agent知识库向量
- **对象存储**：MinIO（本地部署）+ 阿里云OSS（备份），存储用户上传的图片/视频、生成的报告文件
- **服务治理**：
  - 服务发现：Consul
  - 配置中心：Nacos
  - 链路追踪：OpenTelemetry + Jaeger
  - 监控告警：Prometheus + Grafana

### AI引擎层（新增Agent能力）
#### 1. 多模态识别模块（Python生态）
输入层 → 预处理 → 检测模型 → 分类模型 → 后处理 → 输出结果
- **预处理**：OpenCV + Pillow，图像去噪、分辨率统一、格式转换，视频抽帧（每秒1帧+关键帧提取）
- **目标检测**：
  - 基础模型：YOLOv8x（PyTorch），针对房屋场景做fine-tune
  - 检测类别：墙体（裂缝/掉皮）、地面（划痕/破损）、门窗（损坏/密封性）、家电（品牌/状态/损耗）、水电设施（漏水/老化）、家具（损坏/磨损）等30+类别
  - 标注数据集：自建10万+张房屋场景标注数据，持续迭代
- **缺陷分类**：
  - 模型：ResNet152 + SAM 2（Segment Anything Model 2）
  - 能力：识别缺陷类型、严重程度（轻微/中等/严重）、估算修复成本
- **OCR识别**：PaddleOCR，识别电表/水表读数、家电说明书、租赁协议信息

#### 2. LLM智能报告模块
- **基础模型**：
  - 优先：通义千问4V / 文心一言4.0（国内合规，响应快）
  - 备选：GPT-4o / Claude 3 Opus（海外部署）
- **Prompt工程**：角色：专业验房师，有10年租赁房屋验房经验
- **RAG增强**：
  - 内置本地知识库：各地房屋租赁相关法规、常见装修修复价格表、家电正常损耗判定标准、租房纠纷典型案例
  - 向量检索：Milvus + LangChain，实时召回相关知识

#### 3. AI Agent模块（✨ 新增核心能力）
- **Agent框架**：LangGraph + LangChain
- **核心能力**：
  1. **智能验房助手**：
     - 自然语言交互，用户可以用语音/文字描述房屋问题，Agent自动识别并分类
     - 智能引导用户上传照片，根据用户描述动态调整需要上传的点位
     - 自动解答用户关于验房、租房、维修的各种问题
  2. **自动任务执行Agent**：
     - 自动识别用户上传的图片质量，不合格的自动提示重拍
     - 自动调用多模态识别工具，分析缺陷，生成报告
     - 自动调用知识库，给出修复建议和成本估算
     - 自动对接维修服务商API，一键下单
  3. **决策Agent**：
     - 智能判断缺陷严重程度，安全隐患自动升级预警
     - 自动比对历史验房数据，判断新增缺陷和责任划分
     - 智能分析用户需求，推荐合适的服务（验房/租金估价/维修）
- **工具集**：
  - 多模态识别工具
  - 知识库检索工具
  - 网络搜索工具（查最新法规、维修价格）
  - 第三方API调用工具（支付/维修/短信）
  - 报告生成工具
- **记忆管理**：
  - 短期记忆：Redis存储会话上下文
  - 长期记忆：MongoDB存储用户历史交互、房屋信息
  - 记忆检索：向量相似度匹配，召回历史相关信息

#### 4. 状态比对模块
- 支持同一房屋不同时间点的验房结果比对
- 自动标注新增/修复的缺陷，生成退租/续租状态变更报告
- 特征向量相似度比对，防止用户上传旧照片造假
- Agent自动生成比对报告，给出责任划分建议

## 🔧 核心功能实现（新增Agent相关）
### 1. 智能引导上传
- 基于房型自动生成上传指引（比如"请上传客厅正面照/厨房全貌/卫生间墙面"等20+个必拍点位）
- ✨ Agent动态调整：根据用户上传的照片和描述，智能增加需要补充的点位
- 实时检测照片质量，模糊/角度不对/光线太暗时提示重拍
- 支持断点续传，大文件分片上传

### 2. AI处理流程（Agent调度）
用户提交上传 → Agent任务入队 → 预处理 → 多模态识别 → Agent分析 → LLM生成报告 → 人工审核（可选） → Agent推送通知用户
- 处理时长：普通单房源（20张图）≤ 5分钟，带视频的≤ 15分钟
- 异常重试：识别置信度低于80%的自动触发二次识别，仍有问题Agent自动转人工审核
- ✨ Agent主动交互：识别到模糊问题时，主动询问用户是否需要补充照片

### 3. 报告能力
- 支持PDF/Word/网页三种导出格式
- 带防伪水印和唯一验房编号，可作为租房纠纷举证材料
- 支持在线分享给房东/中介，设置查看有效期
- ✨ Agent自动解读报告：用户可以用自然语言询问报告内容，Agent智能解答

### 4. 增值功能
- 租金估价：基于房屋状态和周边市场数据，给出合理租金建议
- 风险预警：识别到严重安全隐患（比如电路老化、燃气泄漏风险）时自动高亮提醒，Agent自动发送短信通知
- 维修对接：对接本地维修服务商，Agent自动推荐合适的维修商，一键下单
- ✨ AI Agent助手：7x24小时在线解答用户关于租房、验房、维修的所有问题

## ⚠️ 风险与应对
1. **AI识别准确率不足**
   - 应对：初期设置人工审核环节，用户反馈错误的样本自动加入训练集，每月迭代模型版本，目标准确率≥95%

2. **Agent决策错误**
   - 应对：设置人类兜底机制，Agent置信度低于90%的决策自动转人工审核，持续优化Prompt和工具调用逻辑

3. **数据安全风险**
   - 应对：用户上传的房屋照片/信息加密存储，报告生成后7天自动删除源文件，符合个人信息保护法规，Agent记忆数据可随时删除

4. **多端开发复杂度**
   - 应对：使用React Native+Expo跨平台方案，共享核心业务逻辑，减少重复开发，一套代码覆盖iOS+安卓+小程序

5. **市场竞争**
   - 应对：持续深耕租赁场景，积累行业数据，构建数据壁垒，AI Agent能力是差异化核心竞争力，比通用AI工具更专业更贴合用户需求
