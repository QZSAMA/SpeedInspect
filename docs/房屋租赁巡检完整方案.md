# 房屋租赁巡检业务方案

更新日期：2026-09-10。2026-03 旧稿保存在 [归档](archive/房屋租赁巡检完整方案-202603.md)。

产品用于建立可追溯的房屋状态证据和双方确认流程，AI 帮助整理可见异常。人与原始证据承担最终确认职责，系统不自动判断法律责任或赔偿金额。

| 阶段 | 能力 | 验收 |
|---|---|---|
| MVP | 单用户巡检、按房间证据、AI 建议、人工修订、版本化报告 | 真实采集到保存导出全链路完成；拒绝跨用户访问 |
| 租赁协作 | 房源、租约、成员关系、限时邀请 | 邀请过期/撤销/转租均不越权；双方确认有版本记录 |
| 入住与退房比较 | 同房间/位置证据配对、时间线、人工确认差异 | 视角或光照不匹配时标记无法比较，不自动认定新增损坏 |
| 维修闭环 | 工单、负责人、报价、状态、完工复核 | 合法状态转换、并发修改和审计均可验证 |
| 商业化 | 套餐、支付网关、通知、退款 | 服务端定价、验签 webhook、幂等账务与对账；模拟支付禁止上线 |

个人只访问自己的巡检；协作阶段按资源 Membership 授权。邀请码必须短期且限制次数，知道房源 ID 不代表有权限。管理员的必要访问需要留审计。

每份证据记录房间、采集时间、资产 ID 和哈希；报告保留 AI 原始建议与人工修订版本。双方存在争议时保留各自意见，不自动覆盖。地址、室内媒体和联系方式按最小必要原则采集。

先用真实手机验证采集、上传、复核的成功率与耗时，再确定效率目标。旧稿中的六周排期、70% 效率提升和行业首创均无证据，不作为当前承诺。技术实施遵循 [Vercel 方案](技术方案.md) 和 [路线图](ROADMAP.md)。
