## 🔍 方案概述

我们为房屋检查系统设计了**三种互补的AI模型训练方案**，每种方案都有其独特的优势和适用场景。

### 方案特点

| 方案 | 核心技术 | 推荐指数 | 主要优势 |
|------|---------|---------|---------|
| **方案1** | YOLOv8 目标检测 | ⭐⭐⭐⭐⭐ | 快速、简单、实时性能好 |
| **方案2** | 多阶段CNN分类 | ⭐⭐⭐⭐☆ | 准确率高、可解释性好 |
| **方案3** | CLIP + Transformer | ⭐⭐⭐⭐☆ | 数据效率高、灵活扩展 |

---

## 📊 方案对比

### 详细对比表

| 维度 | 方案1: YOLOv8 | 方案2: 多阶段CNN | 方案3: CLIP |
|------|--------------|-----------------|------------|
| **核心任务** | 目标检测 (bbox + 分类) | 图像分类 (多阶段) | 图像-文本匹配 |
| **标注要求** | Bounding box + 类别 | 仅类别标签 | 少量/无标签 |
| **推荐数据量** | 100-500/类别 | 200-1000/类别 | 5-50/类别或零样本 |
| **训练难度** | 低 | 中 | 低/中 |
| **推理速度** | 快 (10-100 FPS) | 中 (2-5次前向) | 中/慢 |
| **预期准确率** | 75-90% mAP | 85-95% Top-1 | 70-90% (取决于样本) |
| **部署难度** | 低 | 中 | 中 |
| **硬件要求** | 低/中 | 中 | 中/高 |
| **新类别扩展** | 需要重新训练 | 需要重新训练 | 零样本/少样本 |
| **定位能力** | ✅ 精准bbox | ⚠️ 需结合检测 | ⚠️ 需结合检测 |
| **可解释性** | 中 | 高 | 高 |

### 成本对比（估算）

| 项目 | 方案1 | 方案2 | 方案3 |
|------|-------|-------|-------|
| **标注成本** | 高 (bbox) | 中 (分类) | 低/无 |
| **训练时间** | 短 | 中 | 短/中 |
| **GPU资源** | 中 | 高 | 中 |
| **人力成本** | 低 | 中 | 低 |
| ****总计** | **中** | **高** | **低** |

## 🎯 决策指南

### 快速选择指南

```
开始
│
├─ 有bbox标注？
│  ├─ 是 → 优先方案1 (YOLOv8)
│  └─ 否 → 需要标注或选择方案2/3
│
├─ 数据量如何？
│  ├─ 少 (< 50/类) → 方案3 (CLIP)
│  ├─ 中 (50-500/类) → 方案1 或 方案3
│  └─ 多 (> 500/类) → 方案2 (CNN)
│
├─ 性能要求？
│  ├─ 需要实时 → 方案1
│  ├─ 追求准确率 → 方案2
│  └─ 灵活扩展 → 方案3
│
└─ 标注预算？
   ├─ 高 → 方案1 或 方案2
   └─ 低 → 方案3
```

### 场景推荐

| 场景 | 推荐方案 | 理由 |
|------|---------|------|
| **快速原型** | 方案1 | 开发快，易部署 |
| **最高准确率** | 方案2 + 方案1 | CNN分类+YOLO检测 |
| **有限标注** | 方案3 | 少样本/零样本 |
| **实时应用** | 方案1 | 推理速度快 |
| **频繁加新类** | 方案3 | 无需重新训练 |
| **生产环境** | 方案1 + 方案3集成 | 速度+灵活性 |

## 📁 各方案详情

### 方案1: YOLOv8 目标检测 ⭐⭐⭐⭐⭐

**位置**: [scheme1_yolov8.py](scheme1_yolov8.py) | [README](scheme1_yolov8/README.md)

#### 核心特点
- **模型**: YOLOv8 (n/s/m/l/x 多种尺寸可选)
- **任务**: 端到端目标检测 (定位 + 分类)
- **优势**: 
  - 训练和部署都非常简单
  - 实时性能优秀
  - 社区活跃，文档完善
  - 支持实例分割

#### 工作流程
```
视频帧 → YOLOv8 → 检测bbox + 分类 → 结果输出
```

#### 适用场景
✅ 快速原型开发  
✅ 需要实时性能  
✅ 已有bbox标注  
✅ 移动端/边缘部署  

---

### 方案2: 多阶段CNN分类 ⭐⭐⭐⭐☆

**位置**: [scheme2_cnn.py](scheme2_cnn.py) | [README](scheme2_cnn/README.md)

#### 核心特点
- **模型**: EfficientNetV2 / ConvNeXt / ResNet
- **任务**: 两阶段图像分类
- **优势**:
  - 准确率高
  - 可解释性好
  - 层次化分类
  - 类别均衡处理

#### 工作流程
```
视频帧 → [可选: 检测] → Crop → Stage 1分类 → Stage 2分类 → 结果
```

#### 两阶段分类
```
Stage 1 (粗分类):
├─ 结构问题
├─ 设施问题
└─ 外观问题

Stage 2 (细分类):
├─ 结构问题 → 墙裂缝/地板磨损/天花板...
├─ 设施问题 → 电器/管道/门窗...
└─ 外观问题 → 油漆/霉菌/家具...
```

#### 适用场景
✅ 追求最高准确率  
✅ 有分类标注（无bbox）  
✅ 类别层次清晰  

---

### 方案3: CLIP + Transformer ⭐⭐⭐⭐☆

**位置**: [scheme3_clip.py](scheme3_clip.py) | [README](scheme3_clip/README.md)

#### 核心特点
- **模型**: CLIP (ViT-B/32, ViT-L/14)
- **任务**: 图像-文本匹配，零样本/少样本
- **优势**:
  - 数据效率极高
  - 零样本扩展新类别
  - 自然语言描述问题
  - 提示词工程灵活

#### 工作流程
```
视频帧 → [DETR检测] → Crop → CLIP匹配 → 结果
         (可选)
```

#### 提示词示例
```python
problem_definitions = {
    "wall_crack": "cracks on the wall, wall damage with fissures",
    "water_stain": "water stains, damp spots on ceiling or walls",
    # 新增类别只需添加描述！
}
```

#### 适用场景
✅ 标注数据有限  
✅ 需要灵活扩展  
✅ 零样本快速验证  
✅ 自然语言描述需求
